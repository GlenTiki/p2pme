01

Install the library

The local host runs on your computer. The public website supplies the browser app and instructions. It cannot install a skill inside your agent.

The first release targets Node.js 22 or later. Review the source and release before you install it.

02

Register a session

Open this page from your agent session. Read the p2pme skill instructions and install the versioned skill locally. Then run /p2pme in the session you want to expose.

AGENT SESSION · AFTER SKILL SETUP/p2pme
Host ID
Identifies your local host. Keep one host for the sessions you register on this computer.
Session ID
Identifies one registered agent session. Select this session after you connect to the host.

The skill registers your chosen session. It does not expose every session on your computer.

Claude Code and Codex

Claude Code requires a configured channel. You must register the channel and restart or resume Claude with that channel enabled.

Codex requires a supported session adapter. The adapter must identify the selected thread. A new managed session must be labelled as new.

A skill cannot attach to every running agent session. Follow the adapter instructions for your host.

03

Pair your browser

  1. Open p2pme.glentiki.dev on your phone.
  2. Name the browser and choose whether it should remember the host.
  3. Select Create invitation. Copy the agent prompt to your local session.
  4. Run p2pme pair in your own terminal. Paste the invitation when asked.
  5. Check the displayed scope. Approve the device locally.
  6. Select a registered session to send a message.

You do not need an account. A remembered host lets you return to its registered sessions. You can revoke the device separately from a session.

Your agent keeps its local tool and file permissions. The browser does not approve those actions for you.

UNDER THE HOOD

Two paths. One library.

Native agent peers use Hypercore message logs and Hyperswarm connections. The browser uses WebRTC to reach the local peer.

GitHub Pages serves the static app. Public Nostr relays at nos.lol and relay.damus.io carry encrypted discovery offers. Google and Cloudflare STUN servers help peers connect. These services can see connection metadata.

The app contacts those services only after you select Connect or Create invitation. It operates no hosted chat server. Direct connections can fail on restrictive networks. An operator can supply TURN; that relay can incur costs.
