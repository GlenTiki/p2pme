01

Install the library

The local host runs on your computer. The public website supplies the browser app and instructions. It cannot install a skill inside your agent.

The local host requires Node.js 22 or later. Review the source and release before you install it.

RELEASE · 0.2.0npm install --global https://github.com/GlenTiki/p2pme/releases/download/v0.2.0/glentiki-p2pme-0.2.0.tgz

Install version 0.2.0 from the GitHub release. Check that p2pme --help lists invite and --qr-file. The package includes the CLI, library and skill. After an upgrade, restart the local host and register the selected sessions again.

02

Register a session

Install the pinned release package from step 1. Copy its packaged skills/p2pme folder into your project's skill directory. The live skill page is reference text only. It cannot authorize a device or install itself.

LOCAL HOST · KEEP THIS PROCESS RUNNING p2pme host --workspace /absolute/path/to/project

Copy the packaged skill folder into your project's skill directory. Codex uses .agents/skills/p2pme. Claude Code uses .claude/skills/p2pme.

Invoke $p2pme in Codex or /p2pme in Claude Code. The skill needs the exact current session ID.

Use p2pme register codex THREAD_ID for a supported Codex thread. Use p2pme start codex or p2pme start claude to create a new managed session.

Run p2pme status to check the host ID and session IDs.

Host ID
Identifies your local host. Keep one host for the sessions you register on this computer.
Session ID
Identifies one registered agent session. Select this session after you connect to the host.

The skill registers your chosen session. It does not expose every session on your computer. An agent can keep the host alive in its managed background job.

Claude Code and Codex

For your current Claude session, run p2pme claude-setup CLAUDE_SESSION_ID --output-dir /absolute/new-directory. Use the exact session ID. The command creates separate configuration files and prints a resume command. Exit the selected Claude process first. Run the printed command from the host-approved workspace. Approve the native channel and MCP prompts. Do not run two copies of the same session. The setup command does not edit your existing settings or launch Claude.

Codex requires a supported session adapter. The adapter must identify the selected thread. A new managed session must be labelled as new.

A skill cannot attach to every running agent session. Follow the adapter instructions for your host.

03

Pair your browser

  1. Ask your local agent to use p2pme for the selected session.
  2. The agent checks that the selected session is online. It uses p2pme invite --profiles codex --qr-file /absolute/private-directory/phone.png with a new private temporary directory.
  3. The agent displays the QR image, access and expiry. Scan the image, open its connection link, or enter the code at p2pme.glentiki.dev/live.
  4. Select a registered session after the host connects.
  5. Select Remember host to save access on this browser.

Keep the code and link private. A failed code attempt leaves the QR link available. To replace an invitation, cancel its attempt ID with p2pme cancel-invite ATTEMPT_ID, then create a new one. A too-late result means the grant commit has started; use the grant revocation command to remove access.

You do not need an account. A remembered host lets you return to its registered sessions. You can revoke the device separately from a session. Use p2pme revoke GRANT_ID to revoke host access.

Select --profiles claude for Claude or --profiles codex,claude for both. A profile list is required. The PNG is created locally in a private directory. The agent removes it after connection or expiry. A terminal character grid does not replace the image.

The invitation authorizes one device for the displayed access. The code or QR scan completes pairing without another terminal prompt. The invitation expires after ten minutes. The default grant allows session lists and chat, and expires after 30 days.

Your agent keeps its local tool and file permissions. The browser does not approve those actions for you.

UNDER THE HOOD

Two paths. One library.

Native agent peers use Hypercore message logs and Hyperswarm connections. The browser uses WebRTC to reach the local peer.

GitHub Pages serves the static app. Public Nostr relays at nos.lol and relay.damus.io carry discovery offers. The short code uses password authentication before a private grant exchange. Google and Cloudflare STUN servers help peers connect. These services can see connection metadata.

The browser contacts those services after you select Connect or open a valid QR invitation link. The host contacts them when it creates an invitation or restores an active grant. It operates no hosted chat server. Direct connections can fail on restrictive networks. An operator can supply TURN; that relay can incur costs.
