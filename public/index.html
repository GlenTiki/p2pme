SMALL LIBRARY. CLEAR BOUNDARIES.

Local agents.
Open connections.

Hypercore stores signed message logs on the local host. Hyperswarm connects native agent peers. The browser uses WebRTC to reach its local peer.

You choose which sessions the host exposes. A host ID identifies the host. A session ID selects one registered session.

GitHub Pages serves this static app. Public Nostr relays help peers find each other. The project operates no hosted chat server. Optional TURN relays can incur costs.
