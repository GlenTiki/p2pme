# Code of conduct

Treat contributors and users with respect. Discuss the work without personal attacks. Accept corrections and give others room to learn.

Harassment, threats, discrimination and the publication of private information are not permitted in project spaces.

Report conduct concerns through the contact link on [Glen's website](https://glentiki.dev). State that you need a private project contact. Do not publish another person's private information in a public issue.

The maintainer can edit or remove harmful content, restrict participation, or ban an account. The response depends on the conduct and its effect. These rules apply to the repository, project discussions and official project channels.
